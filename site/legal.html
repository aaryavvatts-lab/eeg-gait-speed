The small print

Notes, privacy and terms for this page. It is a student project written to learn and to be looked at.

Privacy

This is a small static site with no accounts, no forms, no comments and no analytics.

What the page collects

Nothing. There is no tracking code and no advertising on it. It does not ask you for anything.

Outside requests

None. The typefaces, scripts and figures are all served from this site. Earlier versions of this page loaded fonts from Google; that is no longer the case.

What the host can see

Whoever hosts this page, currently Vercel, can keep ordinary server records such as the address your request came from, the same as any website host. That sits outside this page and is covered by the host's own privacy policy.

About the people in the data

The recordings come from a public dataset that its authors anonymised before release, under an approved ethics protocol at their university. It holds no names or contact details, and nothing on this page can be traced back to an individual who took part.

Cookies and storage

This page sets no cookies. It stores one item in your browser's local storage: whether you chose the light or the dark theme, so the choice holds when you come back. Nothing else is stored and nothing is shared.

The interactive controller runs entirely in your browser using data that is already inside the page. It sends nothing out and saves nothing.

If the service hosting this page sets its own cookies, those are covered by that service's policy rather than this one.

Terms of use

This is a student project written to learn and to be looked at. It is offered as is, with no warranty of any kind, and no promise that anything on it is correct or fit for any purpose.

Not medical or clinical advice

Nothing here is medical advice, and none of this is a medical device or part of one. Do not use anything on this page, or the code behind it, to make a decision about anybody's care, treatment, mobility equipment or safety. The wheelchair framing is a way of explaining the problem. The model shown here is nowhere near fit to steer a real chair, and the page says why.

Limits

To the fullest extent the law allows, the author is not liable for any loss or damage arising from use of this page or the code behind it.

The data

The recordings belong to Katmah and colleagues and are published on PhysioNet under a Creative Commons Attribution 4.0 licence, which allows reuse with credit. The dataset itself is not redistributed here.

This page and the code

The text, figures and code written for this project are released under the MIT licence, on the GitHub repository linked in the footer. You may reuse them with credit.

Accessibility

This page aims at WCAG 2.1 level AA.

  • A skip link to the main text, and proper landmarks for the header, the main content and the interactive demo.
  • Every control is a standard HTML input or button, so it works with a keyboard and with assistive software, with focus always visible.
  • Body text holds at least a 4.5 to 1 contrast ratio against its background in both the light and dark theme.
  • The page respects a reduced motion setting. Entrances are dropped and the demo does not animate on its own.
  • Text reflows down to a 320 pixel wide screen. Wide tables scroll inside their own box rather than pushing the page sideways.

The interactive chart is drawn on a canvas, which a screen reader cannot read directly. A written summary next to it updates as the settings change, giving the same numbers in text.

If something on this page does not work with the software you use, the GitHub repository linked in the footer is the place to raise it.
